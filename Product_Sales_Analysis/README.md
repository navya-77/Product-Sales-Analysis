# Product Sales Analysis

## Project Overview
This project analyzes daily product sales using Python. It helps understand sales performance through statistical analysis and data visualization.

## Dataset
The dataset contains daily sales information for one product (Soap) over seven days.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Analysis Performed
- Mean, Median and Mode
- Variance and Standard Deviation
- Quartiles and Interquartile Range (IQR)
- Outlier Detection
- Daily Sales Visualization
- Sales Trend Analysis

## Key Findings
- Saturday recorded the highest sales with 50 units.
- Monday recorded the lowest sales with 10 units.
- The median daily sales were 15 units.
- Saturday's sales were identified as an outlier.

## How to Run
1. Install the required libraries:
   `pip install pandas matplotlib`
2. Run the Python file:
   `python product_sales.py`
